Layihə Haqqında
Bu laboratoriya işinin məqsədi, LinkedList, Stack və Queue verilənlər strukturlarının nəzəri əsaslarını öyrənmək, onları heç bir hazır STL (Standard Template Library) konteynerindən istifadə etmədən sıfırdan C++ dilində implementasiya etmək və eksperimental sınaqlar aparmaqdır.

Tapşırıqlar:
1. Smart Music Playlist (Singly Linked List): Mahnıların idarə edilməsi, əlavə olunması, silinməsi və axtarılması.
2. Browser Undo History (Stack - LIFO): Veb brauzer tarixçəsi və ya mətn redaktorunda "Undo" mexanizminin modelləşdirilməsi.
3. Airport Check-in Queue System (Queue - FIFO): Hava limanında sərnişinlərin qeydiyyat növbəsinin idarə edilməsi.
